> Real physical test mein, digital vernier caliper truth **1.47 mm** thi — Nirikshak ne measure kiya **1.46 mm** — delta sirf **0.01 millimeters**!"_

Isse smartphone camera ek verified digital micrometer ban jaata hai, jo Table-I font schedules ko sub-millimeter precision se verify karta hai."_

# 🛡️ JUDGES CROSS-EXAMINATION DEFENSE CHEAT SHEET (Ready Answers)

Aapke presentation ke baad judges yeh 5 specific questions zaroor puchenge. Inke exact answers yaad rakhein:

### Q1. "Aapne direct GPT-4 ya Gemini Vision API kyu nahi call kar li label check karne ke liye?"

> **Answer:** _"Sir, Generative LLMs probabilistic aur non-deterministic hote hain — wo hallucinate karte hain. Ek hi photo par LLM do alag verdicts de sakta hai. Quasi-judicial notices aur ₹25,000 ke penalties kisi black-box AI guess par issue nahi kiye ja sakte. Isliye humne Deep Learning ko sirf OCR tak restrict kiya, jabki compliance 100% deterministic code (AST Rule Engine) se evaluate hoti hai jo exact Gazette clauses follow karti hai."_

### Q2. "Photo tilt hone par font size galat nahi aayega?"

> **Answer:** _"Bilkul aa sakta hai agar linear scaling use ki jaye. Isliye hum **Planar Homography** calculate karte hain reference card ke 4 corners se. Yeh projective distortion ko mathematically un-tilt karta hai. Physical caliper test par 1.47mm ke mukable hamara measured error sirf 0.01mm tha."_

### Q3. "Remote rural mandi mein internet nahi hua toh?"

> **Answer:** _"Nirikshak mein **Mode B: Offline Field Mode** built-in hai. Localhost par embedded INT8 ONNX models aur local encrypted SQLite database chalta hai. Inspector bina internet ke inspection complete karta hai, aur connectivity aane par signed Merkle dockets cloud se sync ho jaate hain."_

### Q4. "Titan Watch par Unit Sale Price nahi tha, fir bhi pass kaise ho gayi?"

> **Answer:** _"Sir, Rule 6(1)(da) ke 2nd Proviso (G.S.R. 779(E)) ke tehat agar Net Quantity exactly '1 Number' ya '1 Unit' hai, toh Unit Sale Price declare karna statutorily exempt hai! Generic AI isko fail kar deti, lekin hamara engine gazette exemptions ki exact legal depth janta hai."_

### Q5. "Kya eMaap portal ke sath live integration complete hai?"

> **Answer:** _"Sir, Department of Consumer Affairs ne abhi public third-party REST API expose nahi ki hai, isliye live direct webhook production mein DoCA gateway open hone par connect hoga. Lekin NIRIKSHAK ne complete standardized eMaap-compliant JSON schema aur adapter export build kar liya hai — ready for immediate handshake."_
